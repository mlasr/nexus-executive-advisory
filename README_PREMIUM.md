## 🔧 Customização Rápida

### Mudar Cor Primária

Procure por `#d4af37` nos arquivos e substitua por sua cor:

```css
/* Exemplo: mudar para azul premium */
#d4af37 → #1e3a8a
```

### Ajustar Velocidade das Animações

Procure por valores de `animation` e ajuste:

```css
/* Mais lento */
animation: myAnimation 8s ease-in-out infinite;

/* Mais rápido */
animation: myAnimation 3s ease-in-out infinite;
```

### Reduzir Blur em Mobile

Já está otimizado, mas se quiser ajustar:

```css
@media (max-width: 768px) {
  .elemento {
    filter: blur(10px); /* Reduzido de 40px */
  }
}
```

## 🐛 Troubleshooting

### Animações lentas?

**Solução:** Reduzir blur values
```css
/* De */
filter: blur(80px);

/* Para */
filter: blur(40px);
```

### Mouse tracking não funciona?

**Verifique:** JavaScript no final do `index_premium.html` está habilitado.

### Cores parecem diferentes?

**Calibração:** Monitores variam. Teste em múltiplos devices.

## ✨ Filosofia do Design

### Três Pilares

1. **Aspiracional sem ser Inacessível**
   - Luxo que convida, não intimida

2. **Sensual sem ser Explícito**
   - Abstração permite sugestão poderosa

3. **Movimento Orgânico**
   - Animações que simulam vida (respiração, vento, água)

### Por que Funciona

- ✅ Evoca emoção (não apenas informa)
- ✅ Conta histórias (sem palavras)
- ✅ Cria desejo (de pertencer a esse mundo)
- ✅ Diferencia completamente (da concorrência)
- ✅ Funciona tecnicamente (performance + acessibilidade)
